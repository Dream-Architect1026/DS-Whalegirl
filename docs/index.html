01

它解决的是哪一段重复

Positioning

不替你做决定，只把「必须点、必须等、必须抄」的部分接管下来。答题仍走你自己的 DeepSeek Key，判断权在你。

学习通把一门课拆成视频、文档、图书、章节测验四类任务，每类都要人守着点下一步；题目还会用加密字体渲染，复制出来是乱码。DS-Whalegirl 的定位是把这条流水线接上：按 URL 路由判断当前是什么任务，用对应策略推完，再自己游到下一章。

它不改页面结构、不发请求伪造进度，全部操作在你的浏览器里发生；Key 只存本地，费用由你自己在 DeepSeek 侧结算。

02

能做什么

Capabilities

八项能力，全部收敛在页面右下角的一个面板内；非目标页不会挂载。

AI 自动答题

接入 DeepSeek（deepseek-flash / deepseek-v4-pro），覆盖单选、多选、判断、填空。答案按「字母索引 + 文本相似度」双通道回填，兼容 B、A,C、全角 Ｂ 等写法。

自动重问机制

一遍答不出来自动重问，最多 3 遍；连续 3 遍拿不到答案就跳过该题，避免单题无限重试拖死整条流水线。每次尝试都在状态页留痕。

后台挂机守护

浏览器会节流后台定时器、甚至冻结标签页。三条独立手段保活：可见性恢复立刻补 tick、20 秒心跳阻止整体冻结、定时器自动重建不留空洞。最小化也能连续挂机。

视频倍速与卡顿自愈

倍速播放，并在检测到播放器停顿超过阈值时自动戳一下「重播 / 播放」。处于答题暂停状态的视频不会被抢播，触发时留通知。

文档 / 图书 / 作业

自动完成文档与图书任务，章节作业可自动提交，并自动进入下一章节。脚本内部按 URL 路由判断，非目标页不会挂载面板。

加密字体解密

自动还原学习通加密字体，复制与搜题不再是一堆乱码——这是刷题前最影响效率的一环。

API 用量与花费

实时显示请求数、token 数、预估花费与账户余额，区分「本次」与「累计」两套口径。缓存命中 / 未命中改用 API 显式字段，不再错算。

状态页即时响应

状态词库统一收拢，未登记的状态降级为通用文案而非丢弃；日志写入后同帧合并派发，状态展示在 1 帧内更新。

04

怎么装

Install

推荐用脚本猫承载，可自动更新；四步之内就能跑起来。

安装脚本管理器

在 Edge / Chrome 应用商店安装 脚本猫 ScriptCat，也可用篡改猴 Tampermonkey。

安装脚本

在脚本猫脚本页点「安装此脚本」，或打开仓库中的 DS-Whalegirl.user.js 点安装。脚本已配置自动更新地址，后续版本会自己跟进。

配置 AI（可选）

在 platform.deepseek.com 创建 sk- 开头的 API Key，粘贴到面板配置页并选模型。不配也能用，只是不自动答题。

打开课程页面

访问学习通课程页，右下角即出现助手面板。建议先在一门课上前小范围验证，再开启「自动提交 / 自动切换」批量运行。

注意：脚本目前针对 Edge 做了适配，其他浏览器若出现异常请先换 Edge； 生效范围为 chaoxing.com，不是所有 edu.cn 都能用； 请勿同时启用多个脚本管理器并重复安装本脚本，以免双注入。
