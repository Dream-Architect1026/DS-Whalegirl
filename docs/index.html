01

它接的是哪一段

Positioning

不替你做决定，只把「必须点、必须等、必须抄」的部分接管下来。答题走你自己的 DeepSeek Key，判断权在你。

按 URL 路由

四类任务各有一套

视频、文档、图书、章节测验分别判定，用对应策略推完，再自己游到下一章。

不改页面

不发请求伪造进度

全部操作发生在你浏览器里；Key 只存本地，费用在 DeepSeek 侧由你自己结算。

加密字体

先解密再答题

学习通把题目用加密字体渲染，复制出来是乱码；脚本先还原字形，再交给模型。

02

能做什么

Capabilities

八项能力收在一个面板里；非目标页不会挂载。这里只列六项最常用的。

01

AI 自动答题

接入 DeepSeek（deepseek-flash / deepseek-v4-pro），覆盖单选、多选、判断、填空；答案按字母索引 + 文本相似度双通道回填。

02

自动重问

一遍答不出自动重问，最多 3 遍；连续失败跳过该题，避免单题拖死整条流水线。

03

后台挂机守护

浏览器会节流甚至冻结后台定时器。可见性恢复补 tick、20 秒心跳抗冻结、定时器自动重建。

04

视频倍速与卡顿自愈

停顿超阈值自动戳一下重播；处于答题暂停状态的视频不会被抢播。

05

文档 / 图书 / 作业

文档与图书任务自动完成，章节作业可自动提交并进入下一章。

06

用量与花费

请求数、token、预估花费与余额实时显示，「本次 / 累计」两套口径分开算。

03

运行效果

Screens · real

六张实机截图，取自真实课程页运行过程。

04

三步装好

Install

推荐脚本猫承载，可自动更新。

1

装脚本管理器

Edge / Chrome 商店装 脚本猫 ScriptCat，也可用篡改猴。

2

装脚本

脚本页点「安装此脚本」，或打开仓库里的 DS-Whalegirl.user.js；已配自动更新地址。

3

打开课程页

访问学习通课程页，右下角出现面板即生效；要自动答题就在配置页填 sk- 开头的 Key。

注意：针对 Edge 适配；生效范围 chaoxing.com，不是所有 edu.cn 都能用；请勿同时启用多个脚本管理器重复安装，以免双注入。

使用须知

Terms

使用即视为同意以下四组声明；完整六项见脚本须知页。

学习与研究用途

仅供个人学习与研究，遵守学校教学管理规定与平台协议；勿用于代写作业、替考等违规用途。

账号与 Key 安全

脚本不收集、不上传账号密码；Key 只存本地，请勿泄露给他人。

数据与隐私

仅在你主动使用 AI 答题时，向 DeepSeek 发送题目与选项文本；不上传学习记录与个人信息。

费用与风险

费用由 DeepSeek 按你的账户用量计费，作者不承担；与平台冲突（如限流）的后果自行承担。
